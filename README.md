# Ejecutar en desarrollo
1. Clonar el repositoria
2. Ejecutar
```
npm install
```

3. tener NEST-CLI instalado
```
npm i -g @nestjs/cli
```

4. Levantar la base de datos
```
dokcer-compose up -d
```

* MongoDb
